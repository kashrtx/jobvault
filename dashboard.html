Your data

The backup file is the encrypted vault exactly as it sits on disk. Without your master password it is noise. Keep one, because there is no recovery path.

Keep JobVault in the same folder Chrome identifies an unpacked extension by its folder path, and your vault is stored against that identity. Moving or renaming the folder makes this browser treat it as a different extension, and the vault stops appearing. It is not deleted, but the fix is to move the folder back or import a backup. Upgrade by updating the files inside this folder, never by loading a copy from somewhere else.

Automatic backups

Kept inside this browser. One a day, plus one before any update, restore, import or password change. They survive a bad update, but not uninstalling the extension, so keep an exported file too.
